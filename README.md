**AI Engineer · Agents & Automation** · Ecuador (UTC-5).

I build LLM agents that work inside real business systems. They connect to live data through MCP and tool calling, and I measure them by what they change in sales and operations.

I have 13 years in technology, from information security to full-stack software. That background shapes how I design agents: clear permissions, safe tools and planned failure cases.

## What I've built

| Project | What it does | Stack |
|---|---|---|
| **E-commerce MCP server** | Gives MCP clients such as Claude access to sales, Meta Ads, inventory and WhatsApp data, so business questions get answered from live data. | Python · FastAPI · PostgreSQL · MCP |
| **AI sales agent** | Sells on WhatsApp, Instagram and Messenger. Approved through Meta App Review and running in production. | FastAPI webhooks · Gemini · DeepSeek · Meta Cloud API |
| **Competitor monitoring pipeline** | Crawlers track prices, stock and promotions across Shopify, WooCommerce and VTEX stores. | Python · PostgreSQL · AWS |
| **AI creative pipeline** | Collects competitor ads, extracts their hooks and patterns, and generates new ad images and video from catalog data. | Apify · Meta Ad Library · Seedance · Seedream · Nano Banana |
